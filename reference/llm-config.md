All current production llamacpp services set `--flash-attn on` and use `Strategy: Recreate`. The VLM (`cuda-llamacpp-deployment`) additionally sets `--cont-batching` and KV cache `q4_0` (`--cache-type-k/v`). The primary embedder (`embedder-qwen-rocm-deployment`, timmy 9070 XT since 2026-07-06) tunes `--batch-size/--ubatch-size 4096` and drops `--mlock` (control-plane guardrail). `embedder-qwen-cuda` (replicas=0 rollback on wemby) tuned `512` for the 1060. `embedder-llamacpp` was deleted from the cluster on 2026-07-04; `embedder-qwen-rocm` is the sole live embedder.
