All current production llamacpp services set `--flash-attn on` and use `Strategy: Recreate`. The VLM (`cuda-llamacpp-deployment`) additionally sets `--cont-batching` and KV cache `q4_0` (`--cache-type-k/v`). The primary embedder since the 2026-07-17 cutover (IMPR-1077) is Deployment `embedder-qwen-cuda` (`embedder-qwen-cuda-deployment.yaml`, manu GTX 1080, CUDA) — `--batch-size/--ubatch-size 512`, own `embedder-cuda-model-cache` PVC; the neutral `embedder-qwen` Service selects it. The ROCm `embedder-qwen` Deployment (timmy 9070 XT, `--batch-size/--ubatch-size 4096`, drops `--mlock`) is retained as `replicas=1` rollback through the soak, then scaled to 0. `embedder-llamacpp` was deleted from the cluster on 2026-07-04; `embedder-qwen` (the Service) remains the sole live embedder endpoint.
