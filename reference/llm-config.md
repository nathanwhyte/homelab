All current production llamacpp services set `--flash-attn on` and use `Strategy: Recreate`. The VLM (`cuda-llamacpp-deployment`) additionally sets `--cont-batching` and KV cache `q4_0` (`--cache-type-k/v`). The primary embedder (`embedder-qwen-cuda-deployment`) tunes `--batch-size/--ubatch-size 512` for the 1060. The retired `embedder-llamacpp` (replicas=0 rollback) uses `Strategy: RollingUpdate` and does not set `--flash-attn` or `--cont-batching`; `embedder-qwen-rocm` (replicas=0 rollback) is `Recreate` + `--flash-attn` (ROCm).
