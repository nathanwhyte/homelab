## Reading

- **The lane's value on this corpus is mostly subtraction.** 14 of the assessor's top 20 are not worth compacting — live items, load-bearing investigation indexes, reference docs, contract-heavy fences. The human pile that remains (5 chronological collapses + 1 retraction merge, every one on a closed item) is exactly rung 3's safest input.
- **The label-audit pattern repeated.** The model corrected the labeler twice on _semantics_: active items deserve a terminal `not-worth-it` (not a deferred `unclear`), and `proposed` is a live status in this vault, not a dormant one. Both concessions are argued from vault practice, not from chasing the score.
- **Untested paths:** `unclear`, `log-condense`, and `empty-section-removal` have zero positive cases — the fence-heavy candidates all turned out to be contracts, and the final rules leave `unclear` for missing/contradictory statuses only. The next corpus (candidates 21–50) should be sampled to exercise them before those verdicts are trusted.
- Contamination note: the corpus records are the same 20 the exploratory run scored, and the loop adjusted rules against them — this is a fitted training set, not a held-out eval. The honest claim is "the rules encode the adjudications"; the next assess cohort is the real test.
